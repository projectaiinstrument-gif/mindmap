# MIND MATRIX

Standalone browser-based interactive mind map and self-reflection workspace.

## Run locally
Open `index.html` in a modern browser. No build step, server, package installation, or external frontend library is required.

## Data and privacy
The application stores its workspace and preferences in the browser's local storage. Export your data regularly using the application's export controls. If you configure an OpenAI-compatible API key in the AI settings, it is stored locally in this browser; do not use this approach on a shared or untrusted device.
